Library Tutorial

Build a source that XLibrary can read, load, and share.

This guide shows the two supported ways to add external library sources: a normal web collection and a static JSON library. It also explains how to turn your library URL into an XLibrary Key for easier sharing.

Notice

Host and share responsibly

XLibrary does not host external library content for you. If you want to use a custom web collection or JSON library, you are responsible for hosting those files on your own server, website, or storage service.

Please share your library sources only with people you trust, such as friends, family, or private reading groups. XLibrary does not encourage public sharing of illegal content, copyrighted content that you do not have permission to distribute, or any material that may violate local laws, platform rules, or another person's rights.

This tutorial is written for users who are comfortable with basic web hosting, JSON files, URLs, and simple technical setup. If you are new to these topics, take it step by step: start with a normal web collection, then move to JSON format when you are ready.

Choose the right sharing method

Use web collection mode when you only want to share a readable website. Use JSON mode when you want XLibrary to show series, covers, chapters, and reader pages inside the app.

Method Best for App behavior
Web collection
json: false		 Sharing a normal HTTPS website or source page. XLibrary keeps it as a web source.
JSON library
json: true		 Showing series lists and episodes in the reader. XLibrary fetches main.json and episodes.json.
XLibrary Key Sharing a library URL without asking users to paste a long link. The app decodes the key and loads the original HTTPS library URL.

1

Share your web collection (isjson false)

This mode is for a normal web page or website source. XLibrary saves the title, cover, and link, then opens the source as a web collection instead of trying to parse it as JSON.

When to use this

  • Your source is already a website.
  • You do not have main.json and episodes.json.
  • You want users to browse the source in the app browser.
Required: the link should be HTTPS. Non-secure links may be blocked by the app.

Example saved item

{
  "title": "My Web Collection",
  "cover": "https://example.com/assets/cover.jpg",
  "status": "Recent",
  "link": "https://example.com/library/",
  "encrypted": false,
  "json": false
}
2

JSON format only

JSON mode is the format XLibrary can read as a real library. Your base URL must host a main.json file, and every series link must point to a folder that hosts episodes.json.

Folder structure

my-library/
  main.json
  covers/
    space-hero.jpg
  space-hero/
    episodes.json
    chapter-1/
      001.jpg
      002.jpg
The library URL you add to XLibrary should be the base folder: https://example.com/my-library/

main.json example

{
  "series": [
    {
      "category": "Action, Adventure",
      "cover": "https://example.com/my-library/covers/space-hero.jpg",
      "link": "https://example.com/my-library/space-hero/",
      "rating": "4.8",
      "review": "A short description for this series.",
      "series_id": "space-hero",
      "status": "Ongoing",
      "title": "Space Hero",
      "encrypted": false,
      "json": true,
      "view": "12500",
      "last_updated_time": "2026-06-26"
    }
  ]
}

episodes.json example

In the current app code, episode images are read from the content string and split by comma. Keep image URLs separated with commas. 

[
  {
    "episode": "Chapter 1",
    "content": "https://example.com/my-library/space-hero/chapter-1/001.jpg,https://example.com/my-library/space-hero/chapter-1/002.jpg,https://example.com/my-library/space-hero/chapter-1/003.jpg"
  },
  {
    "episode": "Chapter 2",
    "content": "https://example.com/my-library/space-hero/chapter-2/001.jpg,https://example.com/my-library/space-hero/chapter-2/002.jpg"
  }
]

Important rules

  • Use HTTPS URLs for the library, cover images, and chapter images.
  • The base library URL must end with /.
  • main.json must contain a top-level series array.
  • Each series link should point to the folder that contains episodes.json.

Quick test

  1. Open https://example.com/my-library/main.json in a browser.
  2. Open https://example.com/my-library/space-hero/episodes.json.
  3. Confirm both URLs show valid JSON without a login page or redirect error.
  4. Add https://example.com/my-library/ in XLibrary.
3

Create your library as an XLibrary Key

An XLibrary Key is generated from your library URL. It lets you share a shorter app-friendly key while the app still loads the original HTTPS library source.

Steps in the app

  1. Host your JSON library online.
  2. Confirm your base URL works, for example https://example.com/my-library/.
  3. Open XLibrary settings.
  4. Open the library key generator section.
  5. Paste your base URL and tap generate.
  6. Copy the generated XLibrary Key and share it.
  7. Other users can paste the key in Add Library.

How the key is used

The key works as a share-friendly version of your library source. When another user adds the key in XLibrary, the app uses it to open the library URL you prepared.

A key is for convenient sharing. It does not replace your responsibility to host safe, accessible, and correctly formatted library content.
